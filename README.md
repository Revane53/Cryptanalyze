# Caesar Cipher Tool #
## Описание ##
Интерактивное графическое приложение для шифрования и дешифрования текста с использованием шифра Цезаря, а также взлома зашифрованных сообщений методом brute force. Проект разработан с использованием JavaFX и поддерживает расширяемую архитектуру для добавления новых алгоритмов шифрования.

## Основные возможности ##
### 1. Шифрование и дешифрование ###
* Шифрование текста: Введите исходный текст, укажите ключ (сдвиг) и получите зашифрованное сообщение

* Дешифрование текста: Введите зашифрованный текст, укажите ключ (сдвиг) и получите расшифрованное сообщение

* Поддержка русского и английского алфавитов: Обработка букв в обоих регистрах

### 2. Взлом шифра (Brute Force) ###
* Автоматический перебор всех возможных ключей

### 3. Расширяемая архитектура ###
* Интерфейс Cipher: Базовый интерфейс для всех алгоритмов шифрования

* Простое добавление новых алгоритмов: Создайте новый класс, реализующий интерфейс Cipher
